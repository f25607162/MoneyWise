# MoneyWise

MoneyWise is a premium personal finance dashboard built with React, Vite, Tailwind CSS, Recharts, and Lucide icons.

The current release is a fully interactive frontend demo. Financial records, budgets, goals, notification preferences, and profile settings are stored in browser local storage.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
